宝くじ極｜ホーム画面対応版
Version 1.1 / 2026年11月20日

■ 公開サイト
https://uni-tadayasu.github.io/takarakuji/
PC・スマホのブラウザで開いてご利用ください。

■ iPhone・iPadでホーム画面に追加
1. 公開サイトをSafariで開きます。
2. 画面上部の「ホームに追加」で案内を確認できます。
3. Safariの「共有」から「ホーム画面に追加」を選びます。
4. 「ウェブアプリとして開く」が表示される場合はオンにして「追加」を押します。
   項目が見つからない場合は、共有メニューを下へスクロールしてください。
Safariの共有メニューによる操作が必要です。ボタンだけで自動追加はしません。

■ Androidでホーム画面に追加
1. 公開サイトをChromeなどの対応ブラウザで開きます。
2. 「ホームに追加」を押します。
3. ブラウザの追加画面が出たら、端末の確認操作を完了します。
追加画面が出ない場合は、画面の案内に沿ってブラウザのメニュー「⋮」から
「アプリをインストール」または「ホーム画面に追加」を選んでください。
ブラウザによって項目の名前や対応状況は異なります。

■ PCで使う場合
ブラウザでそのまま利用できます。Chrome・Edgeなど対応ブラウザでは、
「ホームに追加」またはアドレスバー／メニューからアプリとして追加できます。

■ オフラインで使う場合
初回はインターネットにつないで公開サイトを開き、追加の案内または設定で
「オフラインの準備ができました」の表示を確認してください。
準備後は、番号作成・収録済みデータの分析・照合・購入ノートを使えます。
公式リンクの閲覧には通信が必要です。抽せん結果は自動更新されません。
ブラウザのサイトデータを消すとオフライン保存も消える場合があります。

■ ファイルをダウンロードして使う場合
GitHubの「Code」→「Download ZIP」からファイル一式を保存できます。
ZIPをフォルダーごと展開し、PCのChrome・Edgeなどでindex.htmlを開くと
基本機能を使えます。ホーム画面追加とService Workerのオフライン機能は
HTTPSの公開サイトで利用してください（開発時はlocalhostも対応）。
index.html、install.js、manifest.webmanifest、sw.js、iconsフォルダーを
同じ相対位置のまま配置してください。
スマホのファイルプレビューではJavaScriptが動かない場合があるため、
スマホでは公開サイトの利用をおすすめします。

■ 使い方
・「番号をつくる」：種類・作成条件を選び、候補を生成します。
・「データを分析」：収録された過去の結果の出現回数や分布を確認します。
・「当せんを照合」：公式結果と自分の番号を照合します。
・「購入ノート」：保存した候補、購入日、受取額、メモを管理します。
・「設定・バックアップ」：予算設定、JSONの保存・復元、CSVの取込を行います。

対応：ロト7／ロト6／ミニロト／ナンバーズ3／ナンバーズ4／ビンゴ5

■ 記録の保存について
購入記録・予算・取り込んだデータは、利用中のブラウザ内に保存されます。
HTMLファイルそのものに購入記録が追記されるわけではありません。
PCとスマホ、別のブラウザ、公開版とダウンロード版の記録は自動同期しません。

ファイルの移動・名前変更・コピーや、ブラウザのデータ削除によって、
以前の記録を参照できなくなる場合があります。
移動・変更の前に「設定・バックアップ」からJSONを保存してください。
別の環境では、そのJSONを読み込んで記録を移せます。
ブラウザへの保存が拒否された場合は画面に警告を表示します。
その場合も、画面を閉じる前にJSONバックアップを保存してください。

■ 抽せんデータと確率
初期収録データ：2026年11月20日に確認した公式結果を各40回、計240回。
これは確認時点のスナップショットで、自動更新ではありません。
追加したい結果は、設定のCSVひな形に合わせて取り込めます。
本数字の回数分析には、ボーナス数字を含めていません。

未来の当せん番号を確実に予知することはできません。
公平で独立した抽せんでは、過去の出現回数や未出現期間を分析しても、
次回の各組合せの確率が上がるわけではありません。
番号生成の条件は、好みに合わせて数字を選ぶための機能です。
ナンバーズのボックス・セットの確率は、数字の重複によって異なります。

照合結果は入力内容に基づく参考判定です。
実際の当せん、抽せん回、受取金額は購入券と公式発表で確認してください。
購入済みの記録や受取額は、利用者が手動で記録します。
アプリが宝くじを購入したり、当せん金を受け取ったりすることはありません。
